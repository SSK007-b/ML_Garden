# Heart Failure Prediction (Random Forest)

## Project Overview
This project predicts the risk of heart failure events using clinical and patient health data.
The aim is to build a reliable and interpretable ML model for healthcare-related predictions.

## Model Used
- Random Forest Classifier
- Handles feature interactions effectively
- Provides feature importance for interpretability

## Features Used
- Patient demographics (age)
- Clinical conditions (anaemia, blood pressure, smoking)
- Cardiac metrics (ejection fraction)
- Blood test results (creatinine, sodium, platelets)
- Follow-up time

## Pipeline Flow
- Data preprocessing and validation
- Feature selection
- Random Forest model training
- Risk prediction

## Output
- Binary prediction: Survival / Death Event
- Can be extended to probability-based risk assessment

## Why This Project?
- Real-world healthcare use case
- Focus on model robustness and explainability
- Demonstrates tabular ML in medical data

## Tech Stack
- Python
- Pandas, NumPy
- Random Forest
- Scikit-learn
